# C Day 91 - Student Record Ranking System

## About
A menu-driven C program to manage student records, search students by ID, and rank them according to marks.

## Features
- Add student records
- View all students
- Search by student ID
- Sort students by marks
- Display student rankings
- Store records in a text file

## Technologies
- C
- Structures
- Functions
- Arrays
- File handling
- Bubble sort and linear search

## Files
- `student_records.c` - Main source code
- `students.txt` - Student records

## How to Run
Compile:

`gcc student_records.c -o student_records`

Run on Windows:

`student_records.exe`

Run on Linux:

`./student_records`

## Data Format
Each line in `students.txt` contains:

`ID Name Marks`

Example:

`101 Rahul 85.50`

Names must be single words in this version.

## Learning Outcomes
Practiced structures, file operations, searching, sorting, and modular programming.
